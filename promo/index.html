GORO Patcher

Cross-platform patcher for Ragnarok Online private servers. Merges GRF files, extracts raw patches, verifies integrity. No dependencies.

Go + Wails v3 Windows / Linux GRF 2.0
Download Source

What it does

Patching

Downloads patches from your URL, verifies with XXHash64, applies safely. GRF 2.0 merge with atomic writes and automatic backup restoration.

Distribution

Build one manifest, serve over HTTP/HTTPS. Download resume, retry with backoff, self-update — all built in. Push patcher builds alongside game patches.

Customization

Wails v3 webview UI. Customize the look with standard HTML/CSS. Display markdown patch notes with custom CSS for server branding.

Features

GRF 2.0 Merge Read/write GRF format. Apply .grf or .zip patches directly into game archives.
Raw Extraction Extract patch contents as raw files. Supports GRF-packed and loose-file distribution.
Download Resume HTTP Range headers with automatic retry and exponential backoff.
Hash Verification XXHash64 checksums on every file. Corrupted downloads detected and re-fetched.
Atomic Writes Temp file swap with automatic backup restoration on failure.
Self-Update Patcher updates itself from the manifest. Push new builds with game patches.
Markdown Notes Display patch notes and announcements. Supports custom CSS branding.
Auto-Check Patch status checked on launch. Players see updates immediately.
Windows Linux Go 1.24+ Wails v3

Quickstart

  1. 1
    Download the latest release from GitHub Releases. Grab the binary for your platform.
  2. 2
    Create patches. Two types: GRF patches merge .grf or .zip into your client's GRF. Raw patches extract non-GRF files (exe, dll, lub) to the game directory. Hash with the included hashfile tool.
  3. 3
    Create plist.json manifest listing your patches, hashes, sizes, and targets. Host it on any static file server (nginx, S3, GitHub Pages, etc.).
  4. 4
    Configure the patcher with goro-config.json next to the binary. Set manifest_url, exe_name, and notes_url pointing to a notes.json that lists markdown files for patch notes, news, or announcements.
  5. 5
    Package & distribute. Bundle the patcher binary, goro-config.json, and your base GRF. Players run the patcher — it checks for updates, downloads, applies patches, and enables Launch Game.
