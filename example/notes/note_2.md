# Patch Notes: v2.1

## Patcher Updates

### Notes System

- Added in-patcher notes display
- Server administrators can now show markdown patch notes, news, and announcements
- Notes are fetched from remote `notes.json` config
- Custom CSS support for styling notes

### UI Improvements

- External links in notes open in default browser (not inside patcher)
- Fixed list bullet padding in notes display
- Drag-and-drop files onto patcher no longer opens them

## Server Changes

### Content

- Added custom NPC in Prontera plaza
- New quest: **The Lost Artifact**
- Updated loading screen tips

### Fixes

- Fixed teleport script in Alberta dock
- Corrected item description for Bloody Branch
